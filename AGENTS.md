# Alutrends page conventions

The user requires every future Alutrends page to reuse the current header and
footer from `alutrends-homepage.html`. Keep their typography, teal–cream palette,
glass styling, motion, responsive layout and keyboard accessibility consistent.
Change these shared designs only when the user requests it.

- Header: brand at left; cart, search and menu at right, in that order. Reuse
  their existing glass dialogs and behavior.
- Navigation and footer topics: Products, Railings, Aluminium System Windows,
  About Us and Customer Reviews.
- Footer: logo at left, the five navigation topics, Contact Alutrends, telephone
  and WhatsApp links for +91 9306566096.
- On inner pages, resolve homepage section links to the homepage or an existing
  destination so navigation remains functional; preserve the labels and design.
- Load the complete shared cart modules and trusted catalogue on every page.
  Follow README.md for integration and same-origin cart persistence.
